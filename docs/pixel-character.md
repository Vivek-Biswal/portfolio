# Pixel character animation

The exterior and Glitch Run use `public/2d/vivek-walk-v2.png`: ten poses in five columns and two rows, comprising idle, eight walking frames, and jump. The arcade explorer uses `public/2d/vivek-room-v2.png`: twelve poses in four columns and three rows, comprising idle and three steps each for down, right, and up; left mirrors right. Both assets were created with the built-in image generation tool using the approved portrait and previous animation as references.

The browser decodes each image once, measures the main silhouette, normalizes scale, and aligns the head and feet. Whole poses keep hands and limbs intact. The earlier portrait and animation assets remain preserved. Room movement, collision bounds, reduced-motion preferences, and cabinet depth ordering use the same character across the scene.
