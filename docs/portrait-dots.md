# Dotted portrait

Final project asset: `public/0d/portrait-dots.png`.

Generated with the built-in image-generation tool from the existing
`public/0d/portrait.jpg`, with Vivek's supplied smiling photo as the identity
reference. The original photo is preserved. The generated image is used on the
0D HTML page, with no client-side JavaScript.

## Final prompt

Use case: style-transfer / identity-preserve. Create a premium editorial dotted portrait for Vivek Biswal's minimal HTML portfolio using the supplied photo as the identity reference. Keep this exact person's recognizable facial proportions, swept black hair, warm smile and eyes. Head and shoulders only, upright, centered. Render the entire portrait exclusively as carefully spaced tiny black circular ink dots on a pure white background, a beautiful stippled halftone diagram with varied dot density, fine facial detail and generous white negative space. The shoulder outline gently dissolves into dots at the bottom. Minimal high-end print design, precise, refined, clean. Simple dark crewneck interpreted in dots, remove all clothing logos. Square composition. No lettering, captions, border, watermark, color washes, continuous solid shading, additional people, or UI. Face should remain clearly recognizable and friendly.
