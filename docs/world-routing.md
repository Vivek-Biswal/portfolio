The former character world is on hold, preserved in source and excluded from production. Its original HTML entry is in archive/character-world/index.html. Its React components, character rig, assets, animation helpers and historical documentation remain intact.

The source folders src/zero, src/one and src/two and asset directories public/0d and public/2d retain their existing names. This avoids disrupting the arcade and saved browser preferences; they are implementation paths, not public world labels. Previous avatar and world guides describe earlier revisions. This file and the current Vercel route list describe the active site.

No administrator system has been implemented yet. Firebase remains a proposal awaiting approval.
